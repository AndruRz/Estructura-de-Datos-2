Research and use all array functions

Que son los Arrays?

Un array es una estructura que permite guardar valores en una sola variable

Ejemplo:

let numeros = [1,2,3,4,5,5];

- Funciones principales de Arrays (Las que debes de usar)

No es obligatorio "todas" las existentes, sino las más importantes. Estas son las que normalmente evalúan:

- Mutan el array

push()      // agrega al final
pop()       // elimina el último
shift()     // elimina el primero
unshift()   // agrega al inicio
splice()    // agrega / elimina en posición específica

- No mutan al array

map()
filter()
reduce()
slice()
concat()
includes()
indexOf()
join()
